# PRD - 個人記帳簿

## 1. 專案概述

- **背景與動機**：學生族群常有生活費管理的需求，希望能清楚掌握每天的收支金流，避免月底超支，因此需要一款介面簡單、好上手的記帳工具。
- **目標用戶**：學生
- **核心價值主張**：設計清晰直覺、操作簡單快速，幫助學生輕鬆紀錄每一筆收支、時間與花費類型，並能隨時掌握目前的生活費餘額。

## 2. 功能需求

以下列出系統主要功能及對應的使用者故事：

1. **記錄收入與支出**
   - 作為 **學生**，我希望 **能快速輸入每筆收入與支出的金額**，以便 **追蹤我的金錢流向**。
2. **紀錄時間**
   - 作為 **學生**，我希望 **在記帳時能選擇或自動帶入發生日期與時間**，以便 **回顧或查詢特定日期的花費**。
3. **顯示餘額統計**
   - 作為 **學生**，我希望 **能在首頁看到總收入、總支出與目前的餘額統計**，以便 **隨時知道自己還剩下多少錢可以花**。
4. **記錄收入與支出的類型**
   - 作為 **學生**，我希望 **能為每筆收支選擇分類（例如：早餐、午餐、購物等）**，以便 **分析我的消費習慣與主要開銷來源**。
5. **輸入收入與支出的備註**
   - 作為 **學生**，我希望 **能在新增收支時輸入備註文字**，以便 **記錄該筆費用的詳細細節或對象（例如：跟室友分攤水電費）**。

## 3. 非功能需求

- **技術限制**：
  - 後端：Python Web 框架 Flask
  - 前端模板：Jinja2 + 自訂的 CSS/HTML (搭配適當響應式 UI)
  - 資料庫：SQLite (確保輕量化)
- **效能與安全考量**：
  - 回應時間需保持在 1 秒內，確保記帳時操作順暢。
  - 需要透過基礎防護機制驗證使用者輸入內容（例如輸入長度限制與金額型別檢查），防止 XSS 與 SQL Injection 攻擊。

## 4. MVP 範圍 (Minimum Viable Product)

| 優先級 | 範圍 (Scope) | 功能項目 |
| ------ | ----------- | -------- |
| 🔴 **Must Have** | 核心記帳與統計 | - 能夠新增/編輯/刪除一筆記帳資料 (包含金額、日期時間、分類、備註)<br>- 首頁顯示當月總收入、總支出與結餘<br>- 條列式顯示所有歷史記帳明細 |
| 🟡 **Should Have** | 簡單報表與分類 | - 提供預設分類選項 (如三餐、交通、娛樂、購物)<br>- 用圖表或比例清單顯示各分類的支出佔比 |
| 🟢 **Nice to Have** | 進階管理功能 | - 使用者可自訂新增自己的分類<br>- 匯出 CSV 報表<br>- 設定每月預算提醒 |
